# 番薯仔大冒險 Han-tsî-á Tāi Mōo-hiám

台語子音、母音的闖關遊戲。番薯仔一路撞「字」磚收集羅馬字字母，跳起來撞正確的字母磚，答對才會開門。

**線頂耍：** https://sinliongtoo.github.io/hantsia-taigi/

## 內容

- 17 个子音、6 个母音、10 个複合母音、5 个鼻化韻、4 个入聲尾音、7 个聲調，每个有 4～5 个例字佮發音說明；看板教頭兩个，題目考無教過的
- 四張地圖，逐張 11 關，上尾一關是魔王關（答對 5 題才拍會倒魔王，答毋著伊會補血）：
  - 環島：夜市、廟口、九份、阿里山、海口、日月潭、太魯閣、合歡山、野柳、台東、環島
  - 台南：赤崁樓、孔子廟、神農街、安平古堡、七股鹽山、四草綠色隧道、億載金城、奇美博物館、烏山頭、鹽水、府城
  - 台北：台北101、龍山寺、西門町、迪化街、士林夜市、淡水、北投、陽明山、貓空、中正紀念堂、大稻埕
  - 高雄：駁二、愛河、旗津、西子灣、蓮池潭、美麗島站、佛光山、衛武營、六合夜市、柴山、港都
- 兩種玩法：闖關版（跳起來撞字母磚）佮戰鬥機版（駛戰鬥機射字母氣球），星星分開算
- 四隻角色會使揀：番薯仔、烏熊、鯪鯉、獨角龜
- 會使切換：漢羅／全羅、台羅／白話字
- 每收集 10 粒珍珠，會補一粒命（上濟 3 粒）
- 「看示範」會自動耍一段予你看

## 操作

闖關版：

| 鍵 | 功能 |
|---|---|
| ← → | 走路 |
| 空白鍵 / ↑ | 跳 |
| P | 暫停 |
| M | 音效 |

手機會出現觸控按鈕。

戰鬥機版：↑↓←→ 飛，會自動射擊；手機用手指拖。

## 備註

拼音用教育部「臺灣台語羅馬字拼音方案」（台羅），會使切換做白話字。例字以通行腔為主，各地腔口有差。

整个遊戲是一个 `index.html`，無需要安裝，直接開就會使耍。
